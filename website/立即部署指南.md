## 🔑 步驟 2：設定綠界金流環境變數

### 從綠界後台取得 API 金鑰

1. **登入綠界後台**
   - 網址：https://vendor.ecpay.com.tw/
   - 使用您的帳號密碼登入

2. **取得 API 金鑰**
   - 前往「系統開發管理」→「系統介接設定」
   - 找到以下資訊：
     - **商店代號**（MerchantID）
     - **金鑰**（HashKey）
     - **向量**（HashIV）

### 在 Vercel 設定環境變數

1. **前往 Vercel 控制台**
   - 打開：https://vercel.com/dashboard
   - 選擇您的項目

2. **設定環境變數**
   - 點擊 **Settings** → **Environment Variables**
   - 點擊 **Add New**，逐一添加：

```
名稱：ECPAY_MERCHANT_ID
值：您的商店代號（從綠界後台複製）

名稱：ECPAY_HASH_KEY
值：您的金鑰（從綠界後台複製）

名稱：ECPAY_HASH_IV
值：您的向量（從綠界後台複製）

名稱：ECPAY_RETURN_URL
值：https://您的網站.vercel.app/api/payment/return
（將「您的網站.vercel.app」替換為實際的 Vercel URL）

名稱：ECPAY_ORDER_RESULT_URL
值：https://您的網站.vercel.app/payment/success
（將「您的網站.vercel.app」替換為實際的 Vercel URL）

名稱：ECPAY_API_URL
值：https://payment.ecpay.com.tw/Cashier/AioCheckOut/V5
（正式環境，審查通過後使用）

名稱：PORT
值：3001

名稱：NODE_ENV
值：production
```

3. **重新部署**
   - 設定完環境變數後，前往 **Deployments**
   - 點擊最新的部署 → **Redeploy**

## ❓ 常見問題

### Q: 如何知道環境變數是否生效？
**A:** 
- 重新部署後，檢查網站日誌
- 或測試付款流程，如果正常就是生效了

### Q: 付款後沒有跳轉回來？
**A:** 
- 檢查 `ECPAY_RETURN_URL` 是否正確
- 確認 URL 是 HTTPS（綠界要求）

### Q: 授權碼沒有生成？
**A:** 
- 檢查付款回調是否正常
- 查看服務器日誌
- 確認 `ECPAY_ORDER_RESULT_URL` 設定正確
