操作說明

1

下載並安裝

下載 App 後，開啟「開發者模式」即可使用（macOS 需要在「系統設定」→「隱私權與安全性」中允許）

2

連接設備

使用 USB 連接您的 iPhone/iPad，點擊 App 中的「初始化連線」按鈕

⚠️ 重要提示：
macOS 版本：點擊「初始化連線」後，系統會彈出 macOS 密碼輸入框，請輸入您的電腦管理員密碼以授予權限。這是為了建立與 iOS 設備的連線所必需的。

Windows 版本：通常不需要輸入密碼，但如果系統提示需要管理員權限，請以管理員身份運行 App 或輸入 Windows 管理員密碼。
3

選擇模式

選擇「瞬移」快速移動到單一地點，或選擇「散花」規劃多點路線

4

儲存最愛

在「最愛」模式中，點擊「加入目前位置」即可儲存常用地點，之後隨時可以快速飛回來！

5

開始使用

點擊「GO」按鈕開始模擬定位，點擊「STOP」即可停止
