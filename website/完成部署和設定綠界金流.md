## 📝 步驟 1：設定綠界金流環境變數

### 在 Vercel 控制台設定

1. **前往 Vercel 控制台**
   - 打開：https://vercel.com/dashboard
   - 選擇您的項目（如果還沒創建，先創建）

2. **設定環境變數**
   - 點擊項目 → **Settings** → **Environment Variables**
   - 添加以下變數（從綠界後台取得）：

```
# 服務器設定
PORT=3001
NODE_ENV=production

# 綠界科技（從綠界後台取得）
ECPAY_MERCHANT_ID=您的商店代號
ECPAY_HASH_KEY=您的金鑰
ECPAY_HASH_IV=您的向量
ECPAY_RETURN_URL=https://您的網站.vercel.app/api/payment/return
ECPAY_ORDER_RESULT_URL=https://您的網站.vercel.app/payment/success

# 授權服務器（如果已部署）
AUTH_SERVER_URL=https://您的授權服務器網址

# 下載連結（等 App 打包後更新）
DOWNLOAD_BASE_URL=https://您的網站.vercel.app/download
MAC_DOWNLOAD_URL=https://您的網站.vercel.app/download/PikminArchitect.dmg
WINDOWS_DOWNLOAD_URL=https://您的網站.vercel.app/download/PikminArchitect.exe
```

**重要**：
- 將 `您的網站.vercel.app` 替換為實際的 Vercel URL
- 從綠界後台取得 `MerchantID`、`HashKey`、`HashIV`

## 🚀 步驟 2：部署網站

### 方法 A：使用 Vercel 網頁界面（最簡單）

1. **在 Vercel 控制台**
   - 點擊 **"Add New..."** → **"Project"**

2. **選擇部署方式**
   - **選項 1**：如果代碼在 GitHub，選擇 **"Import Git Repository"**
   - **選項 2**：如果代碼在本地，使用 CLI（見方法 B）

3. **如果使用 Git**：
   - 先將代碼推送到 GitHub
   - 在 Vercel 中選擇您的 GitHub 倉庫
   - 選擇 `website` 目錄作為根目錄
   - 點擊 **"Deploy"**

### 方法 B：使用 CLI（如果代碼在本地）

在終端執行：

```bash

# 在瀏覽器中完成登入
```

## ❓ 常見問題

### Q: 如何取得綠界的 API 金鑰？
**A:** 
1. 登入綠界後台：https://vendor.ecpay.com.tw/
2. 前往「系統開發管理」→「系統介接設定」
3. 找到「商店代號」、「金鑰」、「向量」

### Q: 付款回調 URL 是什麼？
**A:** 
- `ECPAY_RETURN_URL`：付款完成後跳轉的 URL
- `ECPAY_ORDER_RESULT_URL`：顯示訂單結果的 URL
- 格式：`https://您的網站.vercel.app/api/payment/return`

### Q: 如何測試付款？
**A:** 
- 使用測試環境：https://payment-stage.ecpay.com.tw/
- 測試卡號：`4311-9522-2222-2222`
- 有效期限：任意未來日期
- 安全碼：任意 3 碼
