## 部署步驟

### 步驟 1：登入 Vercel（首次部署需要）

```bash
cd "/Users/rain/Pikmin_Dev_Portable/PikminArchitect＿繼續開發版本/website"
vercel login
```

這會打開瀏覽器，請：
1. 登入您的 Vercel 帳號（如果沒有，先註冊，免費）
2. 授權 CLI 訪問

### 步驟 2：執行部署

```bash
vercel --prod --yes
```

按照提示操作：
- **Set up and deploy?** → 輸入 `Y`
- **Which scope?** → 選擇您的帳號
- **Link to existing project?** → 輸入 `N`（首次部署）
- **What's your project's name?** → 輸入 `pikmin-architect`（或自訂）
- **In which directory is your code located?** → 直接按 Enter（當前目錄）

### 步驟 3：設定環境變數

部署完成後，會顯示您的網站 URL（例如：`https://pikmin-architect.vercel.app`）

1. 前往 Vercel 控制台：https://vercel.com/dashboard
2. 選擇您的項目
3. 前往 **Settings** → **Environment Variables**
4. 添加以下變數（暫時使用測試值，等 API 審查通過後再更新）：

```
PORT=3001
NODE_ENV=production
AUTH_SERVER_URL=http://localhost:3000

# 智付通（Pay2Go）- 推薦，審查最快
PAY2GO_MERCHANT_ID=YOUR_MERCHANT_ID
PAY2GO_HASH_KEY=YOUR_HASH_KEY
PAY2GO_HASH_IV=YOUR_HASH_IV
PAY2GO_RETURN_URL=https://your-project.vercel.app/api/payment/return
PAY2GO_NOTIFY_URL=https://your-project.vercel.app/api/payment/notify

# 藍新金流（備選）
NEWEBPAY_MERCHANT_ID=YOUR_MERCHANT_ID
NEWEBPAY_HASH_KEY=YOUR_HASH_KEY
NEWEBPAY_HASH_IV=YOUR_HASH_IV
NEWEBPAY_RETURN_URL=https://your-project.vercel.app/api/payment/return
NEWEBPAY_NOTIFY_URL=https://your-project.vercel.app/api/payment/notify

# 綠界科技（如果審查通過）
ECPAY_MERCHANT_ID=YOUR_MERCHANT_ID
ECPAY_HASH_KEY=YOUR_HASH_KEY
ECPAY_HASH_IV=YOUR_HASH_IV
ECPAY_RETURN_URL=https://your-project.vercel.app/api/payment/return
ECPAY_ORDER_RESULT_URL=https://your-project.vercel.app/payment/success

# 下載連結（等 App 打包完成後更新）
DOWNLOAD_BASE_URL=https://your-project.vercel.app/download
MAC_DOWNLOAD_URL=https://your-project.vercel.app/download/PikminArchitect.dmg
WINDOWS_DOWNLOAD_URL=https://your-project.vercel.app/download/PikminArchitect.exe
```

**重要**：將 `your-project.vercel.app` 替換為您的實際 Vercel URL。

### 步驟 4：重新部署

設定環境變數後，重新部署：

```bash
vercel --prod --yes
```

   - `PAY2GO_HASH_KEY`

   - 或其他平台的 API 金鑰
3. 重新部署：
   ```bash
   vercel --prod --yes
   ```

## 更容易通過審查的金流平台

### ⭐ 最推薦：智付通（Pay2Go）

**為什麼推薦？**
- ✅ **審查最快**（1-2 個工作天）
- ✅ **個人即可申請**，不需要公司登記
- ✅ **文件要求最簡單**
- ✅ **客服支援好**

**申請網址**：https://www.pay2go.com/

**申請步驟**：
1. 註冊帳號（個人帳號即可）
2. 填寫基本資料
3. 上傳身份證正反面
4. 等待審查（1-2 個工作天）

**費用**：
- 設定費：NT$ 0
- 手續費：信用卡 2.75%，ATM 1.5%

### 備選：藍新金流（NewebPay）

**優點**：
- ✅ 手續費較低（2.5%）
- ✅ 審查相對容易（2-3 天）
- ✅ 知名度高

**申請網址**：https://www.newebpay.com/
