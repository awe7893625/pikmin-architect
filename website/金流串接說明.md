# 金流串接說明

## 費用說明

### 網站費用
- **免費選項**：
  - GitHub Pages（免費，但需要公開代碼）
  - Netlify（免費方案，有流量限制）
  - Vercel（免費方案，適合靜態網站）
  
- **付費選項**：
  - 虛擬主機：約 NT$ 200-500/月
  - VPS：約 NT$ 300-1000/月
  - 雲端服務（AWS/Google Cloud）：按使用量計費

### 金流費用
- **綠界科技（ECPay）**：
  - 設定費：NT$ 0（個人/公司都可申請）
  - 手續費：信用卡 2.75%，ATM/超商 1.5%
  - 最低手續費：NT$ 5
  - 撥款週期：T+1（隔天撥款）
  
- **藍新金流（NewebPay）**：
  - 設定費：NT$ 0
  - 手續費：信用卡 2.5%，ATM 1.5%
  - 最低手續費：NT$ 5
  - 撥款週期：T+1

- **智付通（Pay2Go）**：
  - 設定費：NT$ 0
  - 手續費：信用卡 2.75%，ATM 1.5%
  - 撥款週期：T+1

## 申請流程

### 綠界科技
1. 前往 https://www.ecpay.com.tw/
2. 註冊帳號（個人或公司）
3. 填寫申請表單
4. 上傳身份證明文件
5. 等待審核（約 1-3 個工作天）
6. 審核通過後取得 MerchantID、HashKey、HashIV

### 藍新金流
1. 前往 https://www.newebpay.com/
2. 註冊帳號
3. 填寫申請表單
4. 上傳相關文件
5. 等待審核（約 2-5 個工作天）
6. 審核通過後取得 MerchantID、HashKey、HashIV

## 環境變數設定

創建 `.env` 檔案：

```env
# 綠界科技
ECPAY_MERCHANT_ID=your_merchant_id
ECPAY_HASH_KEY=your_hash_key
ECPAY_HASH_IV=your_hash_iv
ECPAY_RETURN_URL=https://your-domain.com/api/payment/return
ECPAY_ORDER_RESULT_URL=https://your-domain.com/payment/success

# 藍新金流
NEWEBPAY_MERCHANT_ID=your_merchant_id
NEWEBPAY_HASH_KEY=your_hash_key
NEWEBPAY_HASH_IV=your_hash_iv
NEWEBPAY_RETURN_URL=https://your-domain.com/api/payment/return
NEWEBPAY_NOTIFY_URL=https://your-domain.com/api/payment/notify

# 服務器
PORT=3001
```

## 部署建議

### 免費部署選項
1. **Vercel**（推薦）：
   - 免費 HTTPS
   - 自動部署
   - 全球 CDN
   - 適合 Node.js 應用

2. **Netlify**：
   - 免費 HTTPS
   - 自動部署
   - 適合靜態網站

3. **Railway**：
   - 免費方案（有限制）
   - 適合 Node.js 應用

### 付費部署選項
1. **AWS EC2**：約 NT$ 300-1000/月
2. **Google Cloud Platform**：按使用量計費
3. **DigitalOcean**：約 NT$ 300-500/月

## 安全注意事項

1. **不要將 API 金鑰提交到 Git**
2. **使用環境變數儲存敏感資訊**
3. **啟用 HTTPS**
4. **驗證付款回調的檢查碼**
5. **記錄所有交易日誌**

## 成本估算（以 NT$ 490 為例）

假設每月 100 筆交易：
- 綠界科技手續費：490 × 100 × 2.75% = NT$ 1,347.5
- 網站主機費用：NT$ 300-500/月
- **總成本：約 NT$ 1,650-1,850/月**
- **淨收入：49,000 - 1,850 = NT$ 47,150/月**
