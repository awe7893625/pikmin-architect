# Pikmin Architect 使用說明

## 📥 下載與安裝

### 系統要求
- **macOS**：10.15（Catalina）以上
- **Python 3**：需要已安裝
- **iOS 設備**：iPhone/iPad（需要 USB 連接）

### 安裝步驟

1. **下載 App**
   - 從網站下載 `PikminArchitect.dmg`

2. **安裝 App**
   - 雙擊 DMG 檔案
   - 將 `Pikmin Architect.app` 拖到 Applications 資料夾

3. **首次啟動**
   - 如果看到「無法打開，因為來自身份不明的開發者」
   - 前往「系統偏好設定」→「安全性與隱私」
   - 點擊「仍要打開」

4. **安裝依賴**
   ```bash
   pip3 install pymobiledevice3
   ```

---

## 🚀 快速開始

### 1. 連接設備
1. 用 USB 線連接 iPhone/iPad 到 Mac
2. 在 iPhone 上信任這台電腦
3. 在 App 中點擊「初始化連線」
4. 輸入系統管理員密碼（建立 USB 隧道）

### 2. 使用功能

#### 瞬移模式
1. 點擊「瞬移」標籤
2. 在地圖上點擊目標位置
3. 點擊「GO」按鈕
4. 位置會立即移動到目標位置

#### 散花模式
1. 點擊「散花」標籤
2. 在地圖上點擊多個位置（建立路線）
3. 點擊「GO」按鈕
4. 位置會沿著路線移動

## ❓ 常見問題

### Q: 無法打開 App？
**A:** 前往「系統偏好設定」→「安全性與隱私」→「仍要打開」

### Q: 找不到 pymobiledevice3？
**A:** 執行 `pip3 install pymobiledevice3`

### Q: 無法連接設備？
**A:** 
- 確保 iOS 設備已開啟「開發者模式」
- 確保已用 USB 線連接
- 確保已在 iPhone 上信任這台電腦

### Q: 試用次數已用完？
**A:** 前往官方網站購買授權碼升級到完整版

### Q: 授權碼無效？
**A:** 
- 確認授權碼輸入正確
- 確認授權碼未被其他設備使用
- 聯繫客服協助
