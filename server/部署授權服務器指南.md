# 授權服務器部署指南

## 🎯 重要說明

**用戶購買授權時，完全不需要開任何本地服務！**

- ✅ **開發環境**：`localhost:3000` 只是給您自己測試用的
- ✅ **生產環境**：授權服務器必須部署到雲端（Railway、Vercel、Render 等）
- ✅ **用戶端**：用戶只需要訪問購買網站、付款、獲取授權碼、在 App 中激活

---

## 📋 部署方案

### 方案 1：Vercel（推薦，免費）

#### 步驟 1：準備部署

1. **確保 `server/` 目錄有 `vercel.json`**（已創建）

2. **修改 `auth_server.js` 支持 Vercel**：

```javascript
// 在 auth_server.js 開頭添加
const PORT = process.env.PORT || 3000;

// 在文件末尾修改
// 原本：app.listen(PORT, ...)
// 改為：
if (require.main === module) {
    app.listen(PORT, () => {
        console.log(`授權服務器運行在 http://localhost:${PORT}`);
    });
}

// 導出給 Vercel 使用
module.exports = app;
```

#### 步驟 2：部署到 Vercel

```bash
cd server
npm install -g vercel
vercel login
vercel --prod
```

#### 步驟 3：設定環境變數

在 Vercel 控制台：
1. 進入項目設置
2. 添加環境變數：
   - `ADMIN_KEY` = 您的管理員密鑰（用於同步授權碼）

#### 步驟 4：獲取部署 URL

部署成功後，Vercel 會給您一個 URL，例如：
- `https://pikmin-auth-server.vercel.app`

#### 步驟 5：更新 App 代碼

在 `AuthManager.swift` 中，將生產環境的 URL 改為您的 Vercel URL：

```swift
#else
// 生產環境：改為您部署的授權服務器地址
return "https://pikmin-auth-server.vercel.app/api" // ⚠️ 改為您的實際 URL
#endif
```

### 方案 2：Railway（推薦，免費方案）

#### 步驟 1：準備部署

1. 前往 https://railway.app/
2. 註冊帳號（可用 GitHub 登入）
3. 點擊 "New Project" → "Deploy from GitHub repo"

#### 步驟 2：連接 GitHub

1. 將 `server/` 目錄推送到 GitHub
2. 在 Railway 中選擇該 repo
3. Railway 會自動檢測 Node.js 項目

#### 步驟 3：設定環境變數

在 Railway 項目設置中：
- `ADMIN_KEY` = 您的管理員密鑰
- `PORT` = 3000（Railway 會自動設定）

#### 步驟 4：部署

Railway 會自動部署，完成後會給您一個 URL，例如：
- `https://pikmin-auth-server.railway.app`

---

### 方案 3：Render（免費方案）

#### 步驟 1：準備部署

1. 前往 https://render.com/
2. 註冊帳號
3. 點擊 "New" → "Web Service"

#### 步驟 2：連接 GitHub

1. 連接您的 GitHub repo
2. 選擇 `server/` 目錄
3. 設定：
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`

#### 步驟 3：設定環境變數

- `ADMIN_KEY` = 您的管理員密鑰
- `PORT` = 3000

#### 步驟 4：部署

Render 會自動部署，完成後會給您一個 URL。

## 🔧 修改授權服務器支持 Vercel

需要修改 `auth_server.js` 以支持 Vercel 的無服務器架構：

```javascript
// 在文件末尾添加
// 支持 Vercel 無服務器部署
if (require.main === module) {
    const PORT = process.env.PORT || 3000;
    app.listen(PORT, () => {
        console.log(`授權服務器運行在 http://localhost:${PORT}`);
    });
}

// 導出給 Vercel 使用
module.exports = app;
```

---

## 🔄 更新網站服務器同步 URL

部署授權服務器後，需要更新 `website/server.js` 中的同步 URL：

```javascript
// 在 website/server.js 中
const authServerUrl = process.env.AUTH_SERVER_URL || 'http://localhost:3000';
```

在 Vercel/Netlify 部署網站時，設定環境變數：
- `AUTH_SERVER_URL` = `https://pikmin-auth-server.vercel.app`

---

## 📱 更新 App 授權服務器 URL

### 方法 1：編譯時設定（推薦）

在 `AuthManager.swift` 中已經支持：
- 開發環境：自動使用 `localhost:3000`
- 生產環境：使用您設定的雲端 URL

### 方法 2：使用環境變數

在 Xcode 中設定 Scheme 的環境變數：
1. Product → Scheme → Edit Scheme
2. Run → Arguments → Environment Variables
3. 添加：`AUTH_SERVER_URL` = `https://your-auth-server.vercel.app`

## ✅ 完整流程（用戶視角）

### 用戶購買流程

```
1. 用戶訪問購買網站（已部署在 Vercel）
   ↓
2. 點擊「立即購買」→ 選擇付款方式
   ↓
3. 跳轉到金流平台付款
   ↓
4. 付款成功後，網站服務器生成授權碼
   ↓
5. 網站服務器自動同步授權碼到授權服務器（雲端）
   ↓
6. 顯示成功頁面，授權碼顯示給用戶
   ↓
7. 用戶下載 App（已編譯，內含授權服務器 URL）
   ↓
8. 用戶在 App 中輸入授權碼
   ↓
9. App 連接到雲端授權服務器驗證
   ↓
10. 激活成功！
```

**用戶完全不需要開任何本地服務！**
