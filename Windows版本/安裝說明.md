# Windows 版本安裝說明

## 📋 系統要求

- Windows 10 或更高版本
- iOS 設備（iPhone/iPad）
- USB 連接線

## 🔧 必要軟體安裝

### 1. 安裝 Python 3.x

1. 前往 https://www.python.org/downloads/
2. 下載並安裝 Python 3.8 或更高版本
3. **重要**：安裝時勾選「Add Python to PATH」

### 2. 安裝 pymobiledevice3

打開命令提示字元（CMD）或 PowerShell，執行：

```bash
pip install pymobiledevice3
```

### 3. 安裝 libimobiledevice-win32（可選，但推薦）

1. 前往 https://github.com/libimobiledevice-win32/libimobiledevice-win32/releases
2. 下載最新版本
3. 解壓縮並將 `bin` 目錄添加到系統 PATH

或使用 Chocolatey 安裝：

```bash
choco install libimobiledevice
```

### 4. 安裝 iTunes 或 Apple Mobile Device Support

- **選項 A**：安裝完整版 iTunes（包含 Apple Mobile Device Support）
- **選項 B**：只安裝 Apple Mobile Device Support（較輕量）

下載連結：https://support.apple.com/downloads/itunes

## 🚀 使用步驟

### 1. 連接 iOS 設備

- 使用 USB 連接線將 iPhone/iPad 連接到電腦
- 在設備上點擊「信任此電腦」

### 2. 啟動 App

- 雙擊 `Pikmin Architect.exe` 啟動應用程式
- App 會自動檢測設備

### 3. 開始使用

- 點擊地圖選擇位置
- 點擊「GO」按鈕開始模擬
- 點擊「STOP」停止模擬

## ⚠️ 常見問題

### 問題 1：無法檢測到設備

**解決方案**：
1. 確認設備已通過 USB 連接
2. 確認已在設備上點擊「信任此電腦」
3. 確認已安裝 iTunes 或 Apple Mobile Device Support
4. 重新啟動 App

### 問題 2：GPS 模擬失敗

**解決方案**：
1. 確認已安裝 Python 3.x
2. 確認已安裝 pymobiledevice3：`pip install pymobiledevice3`
3. 確認設備已正確連接
4. 嘗試重新連接設備

### 問題 3：權限錯誤

**解決方案**：
- Windows 上通常不需要管理員權限
- 如果遇到權限問題，嘗試以管理員身份運行

## 📝 注意事項

1. **首次使用**：每個設備自動獲得 3 次免費試用
2. **授權激活**：試用次數用完後，需要購買授權碼並在 App 中激活
3. **設備綁定**：每個授權碼只能綁定一個設備
