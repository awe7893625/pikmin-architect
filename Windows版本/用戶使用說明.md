# Windows 版本用戶使用說明

## 🎉 好消息：下載後可以直接使用！

Windows 版本已經優化，**盡可能減少用戶需要安裝的軟體**。

---

## 📥 下載和安裝

### 1. 下載 App

從購買網站下載：`Pikmin Architect Setup.exe`

### 2. 安裝 App

雙擊安裝程式，按照提示完成安裝。

### 3. 首次使用

#### 情況 A：已包含可執行檔（最佳體驗）✅

如果 App 已打包 `pymobiledevice3.exe`：
1. 連接 iOS 設備（USB）
2. 在設備上點擊「信任此電腦」
3. 啟動 App
4. **直接使用！** ✅

**不需要安裝任何額外軟體！**

#### 情況 B：需要自動安裝（備用方案）

如果 App 未包含可執行檔，App 會自動：

1. **檢測 Python**：
   - 如果已安裝 → 自動安裝 pymobiledevice3 → 使用 ✅
   - 如果未安裝 → 顯示提示 → 點擊打開下載頁面 → 安裝 Python → 重啟 App → 自動安裝 pymobiledevice3 → 使用 ✅

2. **自動安裝 pymobiledevice3**：
   - App 會自動執行：`pip install pymobiledevice3`
   - 無需手動操作

---

## ⚠️ 必須安裝的軟體（Apple 官方要求）

### iTunes 或 Apple Mobile Device Support

這是 Apple 官方要求，無法避免。但 App 會自動檢測並引導安裝。

**下載連結**：https://support.apple.com/downloads/itunes

**App 會自動檢測**：
- 如果已安裝 → 直接使用 ✅
- 如果未安裝 → 顯示提示並打開下載頁面 ✅

---

## 🚀 使用流程

### 1. 連接設備

- 使用 USB 連接線將 iPhone/iPad 連接到電腦
- 在設備上點擊「信任此電腦」

### 2. 啟動 App

- 雙擊桌面快捷方式或從開始菜單啟動
- App 會自動檢測設備

### 3. 開始使用

- 點擊地圖選擇位置
- 點擊「GO」開始模擬
- 點擊「STOP」停止模擬

---

## ✅ 總結

**用戶只需要**：

6. **使用！**
