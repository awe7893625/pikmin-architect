# Windows 版本完整打包說明

## 🎯 目標：用戶下載後直接使用

讓 Windows 用戶下載 App 後，**無需安裝任何額外軟體**，直接可以使用。

---

## 📦 實現方案

### 最佳方案：打包 pymobiledevice3 為可執行檔

將 `pymobiledevice3` 打包為獨立的 `.exe` 文件，包含在 App 中。

**優點**：
- ✅ 用戶不需要安裝 Python
- ✅ 用戶不需要安裝 pymobiledevice3
- ✅ 下載後直接使用
- ✅ 最佳用戶體驗

---

## 🚀 打包步驟

### 步驟 1：準備可執行檔

在 Windows 開發環境中（需要 Python）：

```bash
# 方法 A：使用提供的批處理腳本
build-pymobiledevice3.bat

# 方法 B：手動執行
pip install pyinstaller pymobiledevice3
pyinstaller --onefile --name=pymobiledevice3 -m pymobiledevice3
copy dist\pymobiledevice3.exe bin\
```

### 步驟 2：安裝 Electron 依賴

```bash
cd Windows版本
npm install
```

### 步驟 3：打包 App

```bash
npm run build:win
```

### 步驟 4：測試

在 Windows 上測試安裝程式：
- `dist/Pikmin Architect Setup.exe`

---

## ✅ 完成後的效果

### 用戶體驗

1. **下載** `Pikmin Architect Setup.exe`
2. **安裝** App（雙擊安裝程式）
3. **連接** iOS 設備（USB）
4. **點擊**「信任此電腦」（在設備上）
5. **啟動** App
6. **直接使用**！✅

**不需要安裝**：
- ❌ Python
- ❌ pymobiledevice3
- ❌ 任何其他軟體

**只需要**：
- ✅ iTunes 或 Apple Mobile Device Support（Apple 官方要求，但 App 可以檢測並引導安裝）

---

## 🔧 當前實現（自動檢測）

如果無法打包可執行檔，App 會：

1. **自動檢測** Python 和 pymobiledevice3
2. **自動安裝** pymobiledevice3（如果 Python 已安裝）
3. **引導安裝** Python（如果未安裝，顯示提示並打開下載頁面）

**用戶體驗**：
- 如果已安裝 Python → 自動安裝 pymobiledevice3 → 直接使用 ✅
- 如果未安裝 Python → 顯示提示 → 安裝 Python → 重啟 App → 自動安裝 pymobiledevice3 → 使用 ✅

---

## 📝 注意事項

### 必須安裝的軟體（Apple 官方要求）

1. **iTunes 或 Apple Mobile Device Support**
   - 這是 Apple 官方要求，無法避免
   - App 可以檢測並引導安裝
   - 下載連結：https://support.apple.com/downloads/itunes

### 可以自動化的部分

1. ✅ **pymobiledevice3** - 可以打包為可執行檔
2. ✅ **Python** - 如果打包可執行檔，不需要
3. ✅ **設備檢測** - App 自動檢測
4. ✅ **授權系統** - 自動連接雲端服務器
