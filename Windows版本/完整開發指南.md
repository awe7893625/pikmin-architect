## 🚀 快速開始

### 步驟 1：安裝依賴

```bash
cd Windows版本
npm install
```

### 步驟 2：測試運行

```bash
npm start
```

### 步驟 3：打包為 .exe

```bash
npm run build:win
```

打包完成後，會在 `dist/` 目錄生成：
- `Pikmin Architect Setup.exe` - 安裝程式
- `Pikmin Architect.exe` - 可執行檔

## 📋 Windows 用戶使用前準備

### 必要軟體

1. **Python 3.x**
   - 下載：https://www.python.org/downloads/
   - 安裝時勾選「Add Python to PATH」

2. **pymobiledevice3**
   ```bash
   pip install pymobiledevice3
   ```

3. **iTunes 或 Apple Mobile Device Support**
   - 下載：https://support.apple.com/downloads/itunes

### 可選軟體

- **libimobiledevice-win32**（推薦）
  - 下載：https://github.com/libimobiledevice-win32/libimobiledevice-win32/releases
  - 或使用 Chocolatey：`choco install libimobiledevice`

## 🔧 GPS 模擬功能說明

### 實現方式

Windows 版本使用以下方式實現 GPS 模擬：

1. **主要方法**：`pymobiledevice3` (Python)
   - 需要安裝 Python 3.x
   - 需要安裝：`pip install pymobiledevice3`

2. **備用方法**：`libimobiledevice-win32`
   - 使用 `idevicesetlocation` 命令
   - 需要安裝 libimobiledevice-win32

### 工作原理

```javascript
// 瞬移功能
await locationEngine.teleport(lat, lon);

// 路線模擬
await locationEngine.startRoute(points, speed);
```

## 📝 用戶使用流程

### 1. 下載和安裝

1. 從網站下載 `Pikmin Architect Setup.exe`
2. 雙擊安裝程式
3. 按照提示完成安裝

### 2. 首次使用

1. 連接 iOS 設備（USB）
2. 在設備上點擊「信任此電腦」
3. 啟動 App
4. App 自動檢測設備並註冊
5. 獲得 3 次免費試用

### 3. 使用功能

1. 點擊地圖選擇位置
2. 點擊「GO」開始模擬
3. 點擊「STOP」停止模擬

### 4. 購買授權

1. 試用次數用完後，App 顯示激活 UI
2. 訪問購買網站，完成付款
3. 獲取激活碼（6位數字）
4. 在 App 中輸入激活碼
5. 激活成功，永久授權

## ⚠️ 注意事項

### 開發環境

- 需要 Node.js 16+ 和 Electron
- 需要 Python 3.x（用於 GPS 模擬）

### 用戶環境

- 需要 Python 3.x（已安裝 pymobiledevice3）
- 需要 iTunes 或 Apple Mobile Device Support
- 需要 USB 連接 iOS 設備

### 授權服務器

- Windows 版本與 macOS 版本共用同一個授權服務器
- 授權服務器必須部署到雲端（Vercel/Railway/Render）
