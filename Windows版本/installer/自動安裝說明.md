# Windows 版本自動安裝說明

## 🎯 目標

讓 Windows 用戶下載後可以直接使用，無需手動安裝任何軟體。

## ✅ 實現方案

### 方案 1：自動檢測並引導安裝（當前實現）

App 啟動時自動檢測：
1. 檢查 Python 是否已安裝
2. 如果未安裝，顯示提示並打開下載頁面
3. 檢查 pymobiledevice3 是否已安裝
4. 如果未安裝，自動執行 `pip install pymobiledevice3`

### 方案 2：打包 Python 到 App（進階方案）

使用 electron-builder 的 extraResources：
1. 下載 Python 可攜式版本
2. 打包到 App 的 resources 目錄
3. App 使用內建的 Python

### 方案 3：使用編譯好的可執行檔（最佳方案）

將 pymobiledevice3 打包為獨立的 .exe：
1. 使用 PyInstaller 將 pymobiledevice3 打包為 .exe
2. 將 .exe 打包到 App 中
3. App 直接調用 .exe，不需要 Python

---

## 🚀 推薦實現：方案 3（最佳用戶體驗）

### 步驟 1：創建 pymobiledevice3 可執行檔

```bash
# 在開發環境中
pip install pyinstaller
pip install pymobiledevice3

# 打包為可執行檔
pyinstaller --onefile --name=pymobiledevice3 --hidden-import=pymobiledevice3 -m pymobiledevice3
```

### 步驟 2：將可執行檔打包到 App

在 `package.json` 的 `extraResources` 中添加：
```json
"extraResources": [
  {
    "from": "bin/pymobiledevice3.exe",
    "to": "bin/"
  }
]
```

### 步驟 3：修改 location-engine.js

```javascript
// 使用內建的可執行檔
const resourcesPath = process.resourcesPath || app.getAppPath();
const pymobiledevice3Path = path.join(resourcesPath, 'bin', 'pymobiledevice3.exe');

await execAsync(`"${pymobiledevice3Path}" developer dvt simulate-location set --tunnel ${this.udid} -- ${lat} ${lon}`);
```

## 📦 當前實現（方案 1）

App 會：
1. 自動檢測 Python 和 pymobiledevice3
2. 如果缺少，顯示友好的提示
3. 引導用戶安裝（一鍵打開下載頁面）
4. 自動安裝 pymobiledevice3（如果 Python 已安裝）

**用戶體驗**：
- 如果已安裝 Python → 自動安裝 pymobiledevice3 → 直接使用
- 如果未安裝 Python → 顯示提示 → 點擊打開下載頁面 → 安裝後重啟 App → 自動安裝 pymobiledevice3 → 使用
