# Windows 版本一鍵打包指南

## 🎯 目標

打包後的 Windows App 可以讓用戶**下載後直接使用**，無需手動安裝任何軟體。

---

## 📦 打包方案

### 方案 A：包含可執行檔（推薦，最佳用戶體驗）

#### 步驟 1：創建 pymobiledevice3 可執行檔

在開發環境中（需要 Python）：

```bash
# 安裝 PyInstaller
pip install pyinstaller

# 打包 pymobiledevice3
pyinstaller --onefile \
  --name=pymobiledevice3 \
  --hidden-import=pymobiledevice3 \
  --hidden-import=pymobiledevice3.cli \
  -m pymobiledevice3.cli.developer.dvt.simulate_location
```

這會生成 `dist/pymobiledevice3.exe`

#### 步驟 2：將可執行檔放到專案中

```bash
mkdir -p Windows版本/bin
cp dist/pymobiledevice3.exe Windows版本/bin/
```

#### 步驟 3：配置打包

`package.json` 已配置 `extraResources`，會自動將 `bin/` 目錄打包進去。

#### 步驟 4：打包 App

```bash
cd Windows版本
npm run build:win
```

**結果**：用戶下載後，App 內建 pymobiledevice3，無需安裝 Python！

---

### 方案 B：自動安裝引導（當前實現）

如果無法打包可執行檔，App 會：

1. **自動檢測** Python 和 pymobiledevice3
2. **自動安裝** pymobiledevice3（如果 Python 已安裝）
3. **引導安裝** Python（如果未安裝）

**用戶體驗**：
- 如果已安裝 Python → 自動安裝 pymobiledevice3 → 直接使用 ✅
- 如果未安裝 Python → 顯示提示 → 點擊打開下載頁面 → 安裝後重啟 App → 自動安裝 pymobiledevice3 → 使用 ✅

---

## 🚀 完整打包流程

### 1. 準備可執行檔（方案 A）

```bash
# 在 Python 環境中
pip install pyinstaller pymobiledevice3
pyinstaller --onefile --name=pymobiledevice3 -m pymobiledevice3
cp dist/pymobiledevice3.exe Windows版本/bin/
```

### 2. 安裝 Electron 依賴

```bash
cd Windows版本
npm install
```

### 3. 打包 App

```bash
npm run build:win
```

### 4. 測試安裝程式

```bash
# 在 Windows 上測試
dist/Pikmin Architect Setup.exe
```

## 📝 注意事項

1. **iTunes 或 Apple Mobile Device Support**：
   - 這個仍然需要用戶安裝（Apple 官方要求）
   - 但可以在 App 中檢測並引導安裝

2. **設備信任**：
   - 用戶需要在 iOS 設備上點擊「信任此電腦」
   - 這是 Apple 的安全機制，無法自動化

3. **授權服務器**：
   - 必須部署到雲端（Vercel/Railway/Render）
   - 用戶不需要開任何本地服務
